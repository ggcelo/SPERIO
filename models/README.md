# Modelo radiográfico externo

Os pesos do modelo de IA pertencem aos respectivos autores e não são
distribuídos neste repositório.

Para executar a inferência, obtenha o arquivo pelos meios autorizados pelos
responsáveis e coloque-o nesta pasta com o nome:

```text
perio_kpt_oficial_fold0_best.pt
```

O `.gitignore` exclui os arquivos desta pasta, exceto este documento.
Não adicione pesos com `git add -f`. A instalação da aplicação não baixa
automaticamente esse modelo.
