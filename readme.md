# Aplicação de Apoio à Decisão Clínica em Periodontia

Software desenvolvido para integrar:

- classificação periodontal AAP/EFP;
- FINDRISC;
- INTERHEART;
- análise radiográfica de perda óssea periodontal.

O projeto está sendo construído de forma incremental, priorizando
clareza do código, rastreabilidade das decisões e compreensão de
cada etapa do processamento.
